# Content consolidation and scientific review status

## Correction implemented
The lesson renderer previously concatenated more than twenty generations of supplementary academic text onto the same subsection. This produced repetitive explanations, conflicting revisions and unnecessary reading load. It now selects one highest-priority subject-specific academic supplement per subsection while retaining the original lesson, laboratories, media, virtual patients and examination centre. The 25 modules × 17 subsections are unchanged.

The coverage test now uses the same selector as the browser. The module-one supplemental layer is no longer incorrectly reported as absent.

## Limits
This is a systemic editorial and code correction, not an independent medical review of 425 lessons, 510 examination questions, all three translations or external media rights. A subsection may still be too short or academically insufficient. Passing build/tests does not establish academic readiness.
