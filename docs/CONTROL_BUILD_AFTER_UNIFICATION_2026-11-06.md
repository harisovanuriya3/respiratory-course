# Контрольная сборка после унификации экзаменов

Дата: 2026-11-06.
Ветка: integration/respiratory-latest-20261106.

Цель: выполнить автоматическую проверку после унификации банка всех 25 модулей и исправления нормализации пробелов.

Обязательные условия:
- 25 модулей, 17 разделов, RU/EN/KZ;
- по 20 тестов и 20 ситуационных задач в каждом модуле;
- отсутствие точных дубликатов формулировок и вариантов ответа;
- медиатека, изображения, лаборатории и рисование схем;
- построение локального архива, без публикации на Vercel.

Результат определяется только статусом GitHub Actions на точном коммите, а не наличием этого файла.
