# V39 — клинико-физиологический практикум

Добавлены 25 уникальных одновопросных клинико-физиологических случаев, по одному на каждый модуль. Каждый случай содержит конкретные исходные данные, три варианта ответа, автоматическую проверку и объяснение на русском языке. Условия, вопросы и варианты ответов представлены на RU/EN/KZ. Перевод объяснений пока не завершён и явно маркирован как RU. Случаи **не** являются полноценными многоэтапными виртуальными пациентами и не предназначены для клинического применения.

Следующие задачи: экспертная вычитка переводов, многоэтапные сценарии с анамнезом и динамическими данными, проверка браузерного поведения, содержательная рецензия.
