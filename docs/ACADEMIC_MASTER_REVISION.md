# Academic revision across 25 modules and 17 subsection types

This release adds a **topic-specific trilingual academic core** to all 25 modules and a **purpose-specific task** to each of the 17 subsection types, yielding 425 distinct module/subsection combinations in each of RU, EN and KZ. The 25 module cores explain mechanisms and common interpretive errors; the 17 section tasks specify learning activities. Existing laboratory simulations, cases and exams remain available.

## Important limitations

This is a substantial cross-course revision, **not** 425 individually authored full-length monographs. A task tailored by subsection and a core tailored by module do not replace individual, independently peer-reviewed lessons. External image licensing, expert translation review and browser validation remain open. No unsupported bibliographic page numbers were invented. Medical material must be reviewed by qualified instructors before formal adoption.
