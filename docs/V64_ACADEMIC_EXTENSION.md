# V64 — научная редакция начальных разделов

В разделах 1–5 добавлены самостоятельные трёхъязычные академические разборы по ключевым механизмам (альвеолярная вентиляция, морфология газообмена, транспульмональное давление, сопротивление потоку, сурфактант). В разделах «Теория», «Практика» и «Ситуационная задача» размещены дополнительные объяснения и задачи с решениями. Это дополнения, а не замена всей программы. Используются упрощённые модели, условия их применимости указаны в тексте.

Не завершены: самостоятельная редакция всех 425 подразделов, лицензированная медиатека, научная и языковая рецензия, браузерное тестирование.
