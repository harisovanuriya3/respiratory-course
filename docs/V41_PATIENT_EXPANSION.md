# V41: многоэтапные виртуальные пациенты

25 сценариев по три этапа каждый (75 заданий), RU/EN/KZ.

20 новых сценариев построены на проверяемых учебных ситуациях: исходные данные, предметный механизм и интерпретация ограничений. Пять сценариев V40 сохранены.

Ограничения: третий этап в 20 новых случаях имеет общую структуру методологического рассуждения; это не полноценные разветвлённые клинические симуляции. Не использовать для диагностики. Для вузовского применения требуется предметная и языковая рецензия.
