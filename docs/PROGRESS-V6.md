# V6 — Module 5: pressures in the respiratory system

Added a new trilingual module-five.js with six focused physiological explanations, a parameter-controlled pressure/compliance SVG laboratory, five graded examination items with explanations, a quantitative worked case, a virtual patient decision, oral examination questions, glossary, and reading links.

**Scientific scope:** Ptp = Palv − Ppl; illustrative linear compliance ΔV = C(Ptp − 5 cm H2O). This is not a clinical-grade or validated model. No real medical photographs or licensed third-party animations are embedded in this update.

**Validation:** `npm run build` generated 455 pages; `npm run check` passed; `node --check public/module-five.js` passed. Browser and expert/translation reviews remain outstanding. Other modules are still drafts, and the five items are not a complete examination bank.
