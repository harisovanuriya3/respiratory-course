## Незакрытые блокирующие вопросы
- Полная научная проверка 425 подразделов, включая формулы, численные нормы и объяснения.
- Отдельная проверка уникальности, ответов, дистракторов и сложности 20 тестов и 20 задач каждого модуля; наличие интерфейса не равно научной валидации.
- Реалистичные анатомические изображения для каждого модуля: сейчас часть медиа — концептуальные схемы или повторяющиеся тематически общие изображения. Нельзя объявлять это полным анатомическим атласом.
- Полный реестр лицензий, источников, авторов и разрешённых способов использования для внешних иллюстраций.
- Сверка теории с конкретными разделами и страницами первоисточников. Текущие ссылки тематические.
- Профессиональная редактура медицинской терминологии RU/EN/KZ.
- Проверка виртуальных лабораторий, рисования на реальных Android/iOS устройствах, доступности и сохранения результата.
- Проверка последней версии Vercel production против GitHub main.

## Верификация и ограничения
Подтверждено повторным чтением исходных файлов через GitHub: код и ссылки добавлены. Попытка локально клонировать репозиторий и запустить `npm run build && npm run check` не удалась из-за отсутствия DNS-доступа к github.com в среде исполнения. Поэтому ни сборка, ни браузерная проверка, ни новая публикация в Vercel **не подтверждены**. Сохранённые исторические тесты не подменяют свежие.

## Решение
**Условно готово к предпросмотру кода, НЕ ГОТОВО к окончательной академической публикации.** До публикации необходимы полный прогон тестов, визуальная проверка каждого модуля и научная рецензия.
