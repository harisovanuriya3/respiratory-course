## Gate 2: Academic completeness (manual expert verification)
- Each of 25 modules: detailed theory, learning objectives, practical methods, clinical cases, graded tests, explanations, review questions.
- All 3 languages: terminology and scientific proofreading.
- Sources: actual publisher/library records, topical citation links, edition verification, page numbers only when inspected.
- Mathematical equations, units, assumptions and physiological limitations checked independently.
- Exam bank: answer key audit, ambiguous options, duplicates and clinical validity.

## Gate 3: Media and interactive quality (manual browser verification)
- Inventory every image, animation, diagram, video, lab and patient by module and media catalogue.
- Verify anatomical accuracy, licensing, source provenance, captions and accessibility.
- Realistic anatomical imagery adjacent to corresponding theory, reciprocal links to media library.
- Test actual slider behavior and browser console, mobile and desktop layout.
- Distinguish illustrative numeric models from validated physiological simulation.

## Gate 4: User acceptance and publication
- Provide local review archive after all gates above are passed.
- Record user review and corrections.
- Only publish to public hosting after explicit approval.
