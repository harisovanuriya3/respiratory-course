# Этап 1 — доступность инструментов (V61)

Исправлены: возврат фокуса на вызвавшую кнопку при закрытии панели, aria-expanded/aria-controls для трёх кнопок, целочисленная длительность таймера 1–180 минут.

Ограничения: поиск пока по заголовкам, не по тексту уроков; независимая физиологическая рецензия и проверка браузера остаются отдельными этапами.

Дальнейшие этапы: 2) экзаменационные задания и дистракторы; 3) 425 уроков; 4) виртуальные пациенты и лаборатории; 5) медиалицензии и переводы.
