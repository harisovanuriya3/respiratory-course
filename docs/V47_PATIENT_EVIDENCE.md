# V47: Данные исследований для 25 виртуальных пациентов

Добавлены 20 отдельных таблиц физиологических данных и задач на RU/EN/KZ (всего 25). Все данные синтетические, учебные. Ответы проверяются автоматически. Расчёты основаны на упрощённых физиологических уравнениях; они не предназначены для клинических решений.

Уровень разработки: один дополнительный оцениваемый этап с таблицей на пациента. Полноценные ветвящиеся клинические деревья и внешняя экспертная рецензия не завершены.
