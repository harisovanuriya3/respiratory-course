# Контрольные точки разработки учебника

## Правила
- Единственный основной учебник: ветка main; не создавать параллельные учебники.
- Не удалять прежние модули, экзамен, медиатеку, лаборатории, пациентов, анимации, ссылки и переводы.
- Каждый крупный пакет изменений сопровождается автоматической сборкой и проверкой.
- Успешная техническая сборка не равнозначна завершению научного и визуального аудита.
- Контрольные точки фиксируются по номеру запуска GitHub Actions и SHA коммита; архивы GitHub Actions имеют срок хранения.
