# Контрольные точки разработки учебника

## Правила
- Единственный основной учебник: ветка main; не создавать параллельные учебники.
- Не удалять прежние модули, экзамен, медиатеку, лаборатории, пациентов, анимации, ссылки и переводы.
- Каждый крупный пакет изменений сопровождается автоматической сборкой и проверкой.
- Успешная техническая сборка не равнозначна завершению научного и визуального аудита.
- Контрольные точки фиксируются по номеру запуска GitHub Actions и SHA коммита; архивы GitHub Actions имеют срок хранения.

## Последующие изменения
- Добавлены специализированные лаборатории альвеолярного газового уравнения и транспорта кислорода, а также локализация предупреждений.
- Для новой контрольной точки требуется отдельный успешный запуск на актуальном SHA. До получения результата не обозначать новый коммит как проверенный.
- Перед финальной публикацией: научная вычитка RU/EN/KZ, инвентаризация медиатеки с правами, проверка всех лабораторий в браузере, контроль качества экзаменационных заданий и клинических сценариев.
