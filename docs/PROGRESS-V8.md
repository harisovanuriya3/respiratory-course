# Version 8 — scope and validation

Module 6 has dedicated content for all 17 routes, including an animated airway-radius experiment, a five-question graded examination, and a guided clinical physiology case. Material is provided in RU/EN/KZ. The model follows the idealized Poiseuille radius-to-resistance relationship and explicitly does not claim to model the full airway tree. External educational media are linked, not redistributed.

Validation: `npm run check`, `npm run build`, `node --check public/module-six.js` succeeded. Build produced 455 static pages (425 lesson routes). Browser end-to-end tests and expert review have NOT been performed. Other modules retain their earlier draft status. This release is NOT a complete university textbook.
