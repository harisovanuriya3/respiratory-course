# V92 — Улучшение экзаменационного разбора

В экзаменационном центре теперь отображаются выбранный студентом ответ, правильный ответ и объяснение по каждому вопросу; также добавлена разбивка результата по разделам. Данные экранируются перед вставкой в HTML. Изменения касаются только интерфейса анализа экзамена, а не научной проверки банка из 510 вопросов.

Ограничения: проверка научной достоверности всех вопросов, качество переводов, лицензии и браузерные E2E-тесты требуют отдельной работы.
