# Respiratory physiology course — release status (15 October 2026)

## Verified in this build
- 25 modules and 17 subsection routes per module (425 subsection routes).
- Site build and existing automated acceptance suite completed successfully.
- 75 trilingual module concept diagrams corrected: Russian, English and Kazakh labels now follow the selected interface language, with a dedicated regression test.
- Internal project assets and the examination and laboratory code are preserved from the preceding release candidate.

## Not verified / not academically certified
- All 425 lessons have **not** received independent line-by-line scientific review.
- The three-language medical translations have **not** been professionally proofread.
- Every laboratory and virtual patient has **not** been validated against clinical or experimental reference data.
- All third-party media assets have **not** been individually license-cleared.
- Full desktop/mobile browser interaction testing has **not** been completed in this run.
- The content-quality test flags 79 subsections whose *supplementary* text is under 250 characters in at least one language; this does not establish the total length of the lesson.

This package is a functioning, automated-test-passing **release candidate**, not a certified academic textbook. The presence of all routes must not be conflated with complete scientific validation.
