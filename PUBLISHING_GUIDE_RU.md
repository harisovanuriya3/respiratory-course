# Публикация академической версии respiratory-course

Этот архив содержит полный проект, а не только папку public.

## Проверка комплекта

- `npm run acceptance` — успешно выполнено 16 октября 2026 года.
- Создаются 456 HTML-страниц: обложка, 4 раздела-хаба, 25 модулей и 425 страниц подразделов, плюс 404.
- Проверка содержания не заменяет научную и клиническую экспертизу. Некоторые короткие разделы и права на внешние изображения требуют дополнительной проверки.

## Безопасная публикация

1. Сохраните резервную копию репозитория GitHub.
2. Не объединяйте текущий PR #1: в ветке academic-full-25 находятся не все файлы полного комплекта, а ветки имеют конфликты.
3. Создайте НОВУЮ ветку от main, например `academic-release-complete`, либо новый тестовый репозиторий.
4. Загрузите в корень новой ветки ВСЁ содержимое этой папки `respiratory-course` (папки docs, public и корневые файлы), с заменой старых файлов. Не загружайте сам ZIP как один файл.
5. Убедитесь, что `public/app.js` начинается с `import {academicMasterChapter}` и что `public/index.html` подключает `/app.js`.
6. Проверьте сборку (`npm run acceptance`), затем предварительную публикацию Vercel (Preview).
7. Откройте /modules/1/theory?lang=RU, /modules/10/theory?lang=EN, /modules/25/theory?lang=KZ, /patients, /exam и /labs.
8. Только после успешного просмотра и проверки консоли браузера переносите версию в main.

Vercel: build command `npm run build`, output directory `dist`. Публикация на основной домен произойдет только после обновления production-ветки.
